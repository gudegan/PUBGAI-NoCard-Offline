# PUBGAI 免卡离线启动版

> **公益破解 · QQ群：777410175**

免卡密、免联网，直接离线启动的破解成品。

## 使用

1. 把所有文件下载到**同一个目录**（保持单层结构，不要再嵌套一层同名子目录）。
2. **双击 `Start.cmd`** 启动（首次会弹 UAC，需管理员权限）。
3. 退出后双击 **`Restore.cmd`** 还原环境。
